# Habal Fare Calculator - PWA

Fare estimate, ride tracking, daily earnings with Telegram bot.

**Author:** © Edwin Macatangay Perez

## Features
- 🛵 Fare calculation (Manila rates)
- 📍 Auto route distance + GPS tracking
- ⛽ Gas consumption (visible)
- 💰 Daily kinita tracker
- 📤 Send to Telegram bot (simple price + time details)
- 📱 PWA installable

## GitHub Pages Setup

1. Create new repo: `habal-fare` (or any name)
2. Upload all files in this folder to repo root:
   - index.html
   - manifest.webmanifest
   - sw.js
   - icon-192.png
   - icon-512.png
   - .nojekyll
3. Go to repo Settings > Pages
   - Source: Deploy from branch
   - Branch: main / root
4. Save. Your site will be live at `https://YOUR_USERNAME.github.io/habal-fare/`

## PWA Install
Open site on phone > Add to Home Screen.
